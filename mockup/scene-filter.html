工位场景 · 显示规则优化

📦 SalaryJump-3.58-scene.apk —— ①「在家/在路上」的 4 种姿势不再画工位； ② 修复戳小人时灯光闪灭；③ 午休/周五的灯改为亮着（人还在工位）。

1不再画工位（在家 / 在路上）

这些状态人不在公司，只显示小人本身 —— 场景语义更诚实。

2保留工位（在公司）

按「是否在用电脑」决定灯光：工作亮（屏幕+台灯+热气）/ 下班灭。

3另一个修复：灯光不再闪灭

戳小人的互动反应现在继承底座状态的灯光（此前固定为"工作亮"，会闪一下）。
修复前：下班后戳小人 → 工位的灯突然亮起（几秒后又灭）❌
修复后：下班后戳 → 灯保持灭 ✓｜工作时戳 → 灯保持亮 ✓｜在家戳 → 仍不画工位 ✓

4完整规则表

姿势工位灯光
通勤赶路不画—（在路上）
躺平快乐不画—（在家）
今日休假不画—（在家）
周日晚焦虑不画—（在家）
元气搬砖 / 硬撑 / 干饭 / 加班 / 出勤 / 周一 / 周五显示💡 亮
下班快乐显示🌙 灭（刚离开）
为什么「下班快乐」保留工位？
叙事上：你刚下班（人可能还在工位收拾东西），桌子留着、灯灭了 —— 这个画面比"空无一人"更有故事感。
而通勤/躺平/休假/周日晚是明确「不在公司」，所以不画。
