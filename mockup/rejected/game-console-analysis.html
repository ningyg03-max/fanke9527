小人拿游戏机 · 方案分析

结论：能做，但「下班」和「周末」得用两种姿态 —— 它们本来就是两个不同的骨架。

1现在这两个场景

场景当前姿势特征
下班后OFF_WORK站着举手欢呼 + 星光 + 彩带飘落
周末WEEKEND躺着靠枕头（白天睁眼 / 深夜 ZZZ）

「站着欢呼」和「躺着」是两套骨架 —— 游戏机要分别贴，不能共用。

!关键：游戏机怎么「出现」

方案说明成本
① 一直是这两个时段永远拿着小
② 点一下点小人 → 掏出玩 5 秒 → 自动收起中
③ 随机进入时一定概率拿（如 40%）小～中
我倾向 ②：「下班后一直低头打游戏」会让本来该是放松喜悦的状态看起来像沉迷手机； 而且每天看到同一个人低头玩游戏，很快就腻。

② 是彩蛋式互动：不点就看不到，原有「欢呼 + 星光」的庆祝感完全保留。

3三个方案

推荐A · 点一下掏出来玩

点小人 → 掏出游戏机玩 5 秒（下班站着玩 / 周末躺着玩）→ 自动收起。 原有点击反应（惊讶/欢呼/害羞）保留，游戏机是额外的一种反应。

不点就看不到，原有观感完全不变。

改动：一个 reaction 类型 + 两个绘制方法 · 中等

备选B · 这两个时段一直拿着

进到下班/周末自动拿游戏机，不用点。

风险：下班后一直低头打游戏，把「下班喜悦」变成「沉迷手机」； 而且每天看到同一个人低头玩，很快腻。

改动：两个绘制方法 + 分发分支 · 小

备选C · 一定概率（40%）

进入时随机决定今天拿不拿。

风险：切后台再回来人可能就换样子了，不稳。 若做，建议按「日期+时段」做随机种子 → 同一天内稳定。

改动：小

4必须定的细节

问题建议
玩多久5 秒（普通反应 2 秒、庆祝 3 秒 —— 玩要看得见）
再点一次提前收起（不用等 5 秒）
周末深夜 0–7 点不掏（那时在睡觉，已经是闭眼 + ZZZ）
加班中不掏（加班打游戏太违和）
游戏机样子横握掌机：屏幕 + 方向键 + 两颗按钮，配色跟随主题
动画屏幕微微闪烁（两帧交替）即可
推荐 A：① 原有观感不变（不点看不到）② 是可发现的小惊喜 ③ 不会把「下班喜悦」变成「低头沉迷」

工作量：两个绘制方法（站姿 + 躺姿）+ 一个 reaction 类型 + 上下文限制。跟 v3.62「连戳彩蛋」差不多量级。

  • 周末深夜（0–7 点）不掏游戏机，对吧？
  • 加班中要不要允许？（我建议不允许）
