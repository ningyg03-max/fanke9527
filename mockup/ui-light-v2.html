浅色模式重构 · v2

深色保持 v1 不变，三版浅色按各自方向重新设计。本页的呼吸点、扫光、光晕漂移、胶囊辉光均为真实动效，建议在浏览器打开观察。

v1 浅色的四个通病（本版逐条修复）
  • 卡片与背景"白对白"，没有对比 —— 界面"糊"在一起
  • 阴影太弱 → 没有纵深，卡片像贴纸
  • 薄荷绿在浅底上发灰，没有存在感
  • 光晕像"脏渍"浮在背景上，而不是氛围
A2

Aurora Glass · 极光玻璃（浅色重构）

极光完整透出 + 玻璃更"实" —— 保留氛围，补上对比与纵深

浅色模式 · v2
v2 修了什么四条通病全覆盖
  • 背景不再"近白雾面"：改为青绿倾向的柔光渐变，三层极光（绿 34% / 青 26% / 紫 17%）完整透出并缓慢漂移
  • 玻璃更"实"：白色占比提到 62–86% + 白色描边（1px 近乎不透明白）→ 卡片从背景里"立"起来
  • 纵深双保险：白色内高光（顶部 1px 亮线）+ 绿色调柔影（26px 投影，色相跟着主题走，不再是灰影）
  • 强调色加深：薄荷 → 翡翠 #0B9E7D；「加班中」渐变胶囊 + 呼吸辉光（真实动效）
  • 数字：深墨绿 + 极淡绿色辉光，浅色下也有"发光感"但不刺眼
B2

Porcelain · 珠光瓷白（浅色重构）

纯白瓷片 + 双层柔影 —— 白卡必须真正"白"，层次靠光影不靠描边

浅色模式 · v2
v2 修了什么对比 + 纵深
  • 卡片从"半透明"改为纯白瓷片：#FFFFFF 实色 —— 瓷白方向的白卡必须真正白
  • 双层柔影浮起：近距小影（1px/2px 定形）+ 远距大影（46px 扩散定纵深）→ 卡片像放在桌面上的瓷片，有物理感
  • 背景压暗一档（#F0F8F5）：拉开"背景灰绿 ↔ 卡片纯白"的明度差，杜绝白对白
  • 描边减到最淡（4.5% 透明度）：让圆角与阴影说话，保持"轻盈"
  • 强调色：青绿 #0FA98A 实色瓷釉质感；按钮为实色 + 柔影，无辉光（静音式反馈）
C2

Obsidian · 曜石极简（浅色重构）

纯白卡 + 发丝描边 + 渐变文字 —— Linear 浅色模式同款思路

浅色模式 · v2
v2 修了什么精密感 + 光泽
  • 卡片改纯白 + 发丝描边（7% 黑）：Linear 浅色同款 —— 层次靠描边与留白，阴影极小
  • 数字改渐变文字（石墨 #26292B → 翡翠 #0A8A6C，自上而下）：浅色下也有"光泽"，这是 C 方向的核心签名
  • 背景：#F7F8F8 中性底 + 顶部极淡绿光（8%），冷静精密
  • 强调绿加深 #0A8A6C：浅底上足够锐利；胶囊为描边式（透明底），选中态加粗描边
  • 进度线 3px 精细线：去掉高光扫动，保持"几乎看不见但能感觉到"的克制
对比 · 三版浅色各自的性格
  • A2 极光：光影流转让页面"活着" —— 氛围最强，仍是三版里最有"未来感"的
  • B2 瓷白：最干净、最通透 —— 白卡与灰绿底的明度节奏，像精品酒店的卫浴瓷砖
  • C2 曜石：最精密、最"工具感" —— 渐变文字 + 发丝描边，浅色下的 Linear
  • 💡 若纠结：深色用 A（氛围），浅色用 C2（精密）—— 同 App 明暗各有性格，但配色系统同源（翡翠绿 + 青绿）
