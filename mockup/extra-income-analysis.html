1计算规则（这部分现在就是对的）

// 拆分定义：先算加班，日薪 = 总额扣掉其余三项 加班费 = 当天入账 − 应得 ← 应得里已含外快 日薪 = 入账 − 加班费 − 外快 − 补录 // 恒等式（任何组合都不破） 日薪 + 加班费 + 外快 + 补录 ≡ 当天入账

关键点：外快不会被误算成加班。因为「应得」= 外快 + 日薪， 加班费算的是「超出应得的部分」，外快已经先被排除了。 这条已有回归测试锁住（外快不算加班 / 没有误判成加班）。

当天到手包含外快 —— 那天赚的就是这些，一起计入月合计和存钱罐。

保持你已确认的「日薪 + 加班费」两行，为外快再加一行。格子高度 52 → 58dp。
