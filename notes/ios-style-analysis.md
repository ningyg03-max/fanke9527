# iOS「精致感」拆解与三套方案

日期：2026-10-09 · 状态：**仅分析，未修改代码**

---

## 一、先说结论

「精致感」不是某个颜色或某个圆角，而是**五条规则的叠加**：

| # | 规则 | 具体做法 | 为什么有效 |
|---|---|---|---|
| 1 | **层级用灰阶，不用描边** | 背景 `#F2F2F7`，卡片纯白，靠亮度差分区 | 描边是"工程感"，亮度差是"印刷感" |
| 2 | **一个强调色，其余全灰** | 全局只有 1 个彩色的语义色（iOS 蓝 `#007AFF` 或系统绿） | 颜色越少，每个颜色越有分量 |
| 3 | **数字才是主角** | 34–40sp、`-1.2px` 字距、等宽数字、货币符号降级缩小 | 大字号 + 紧字距 = "精密仪器"观感 |
| 4 | **边框全 0.5px，圆角克制** | 分隔线 `0.5px`（不是 1px），圆角 12–16dp（不是 22–24dp） | 细线 + 小圆角显得"贵"，粗线大圆角显得"卡通风" |
| 5 | **留白比装饰重要** | 卡片内边距 16–20dp，元素间距成倍关系 | iOS 的"呼吸感"来自间距节奏，不是阴影 |

### 再补三条"手感"细节

- **字重只用 400 / 600 / 700**，不用 500（Android 默认字体的 Medium 在中文字形上会发虚）
- **等宽数字**（`tabular-nums`）：金额滚动时数字不跳位，这是"精密"的关键
- **点按反馈**：iOS 不用水波纹，用 **0.95 缩放 + 透明度变化**

## 二、你当前设计的"不 iOS"之处

对照上面五条，现状（2.8）的问题：

| 现状 | 问题 | 属于哪条 |
|---|---|---|
| 翡翠渐变主卡（绿→青→蓝四色渐变） | 颜色太多，渐变色在 iOS 语境里属于"拟物娱乐风" | 规则 2 |
| 卡片圆角 22–24dp | iOS 卡片是 12–16dp；22+ 是 Material You 语汇 | 规则 4 |
| 卡片投影 `0 4px 18px` | iOS 几乎不用投影（除非是浮起元素），用亮度区分 | 规则 1 |
| 主按钮渐变 + 绿色投影 | iOS 主按钮是**纯色**，不要渐变和彩色阴影 | 规则 1/2 |
| 标题 19sp「SalaryJump」 | iOS 用 30–34sp 大标题（Large Title） | 规则 3 |
| 有 logo 图标 | iOS 应用内几乎不放 logo，标题即品牌 | 规则 3 |

> **一句话**：现状是"**明亮的消费级 App**"，iOS 精致感是"**冷静的工具型 App**"。方向不同，不是好坏问题。

## 三、三套方案

### 方案 A · iOS 原生

**（见图 `ios-style-options.jpg` 第 ② 列、`ios-style-detail.jpg` 第 ① 列）**

| 维度 | 做法 |
|---|---|
| 背景 | `#F2F2F7` 纯灰 |
| 卡片 | 纯白、圆角 **12dp**、**无边框无投影** |
| 标题 | **30sp 大标题**「薪资」+ 13sp 灰色日期 |
| 金额 | 34sp 黑字、`-1.2px` 字距、`¥` 缩到 22sp 灰 |
| 状态 | 15sp 系统绿 `#34C759` |
| 进度条 | **4dp 细条**，圆角 2dp |
| 按钮 | 主按钮**纯绿 46dp 圆角12**；次按钮浅灰底 |
| 数据行 | 4 列网格，**只留数字**（300.00），单位在下 |
| 导航链接 | iOS 蓝 `#007AFF`，右侧带 `›` 箭头 |

**气质**：干净、克制、像苹果自带的"健康"或"股市"。

---

### 方案 B · iOS 深色数据卡

**（见图第 ③ 列 / 细节图第 ② 列）**

**唯一的核心差异：把主卡做成深色 + 环形进度**

| 维度 | 做法 |
|---|---|
| 主卡 | `#1C1C1E` **纯深色**（不是渐变），圆角 20dp |
| 进度 | **环形**（conic-gradient），96dp，环宽 10dp，中间显示 `29%` |
| 金额 | **38sp 纯白**，在深底上冲击力极强 |
| 数据行 | 白色数字 + 半透明白标签，分隔线 `rgba(255,255,255,.13)` |
| 其余卡片 | 与方案 A 相同（纯白 + 12dp 圆角） |
| 主按钮 | **iOS 蓝** `#007AFF`（与深色卡形成冷暖对比） |

**气质**：像 Apple Fitness 的"活动圆环"——**数据感、成就感**。

> 关键：深色卡与周围的浅色卡片形成 **1:3 的明度对比**，这是整个页面唯一的"视觉重音"。

---

### 方案 C · 毛玻璃通透

**（见图第 ④ 列 / 细节图第 ③ 列）**

| 维度 | 做法 |
|---|---|
| 背景 | 浅灰蓝底 + **3 个模糊光斑**（绿/蓝/紫，blur 46px） |
| 卡片 | `rgba(255,255,255,0.62)` + `backdrop-filter: blur(20px)` + **0.5px 白描边** |
| 圆角 | **20dp**（通透材质需要更大圆角才"软"） |
| 颜色 | 保留你的翡翠绿作为强调色，但只用在进度条和主按钮 |
| 主按钮 | 渐变（唯一允许渐变的地方）+ 柔和绿色投影 |
| 次按钮 | 半透明白 + 毛玻璃 |

**气质**：最"新"——接近 iOS 26 的 Liquid Glass 方向，**通透、轻盈、有空气感**。

## 四、三套方案对比

| 维度 | A · iOS 原生 | B · 深色数据 | C · 毛玻璃 |
|---|---|---|---|
| 像 iOS 的程度 | ★★★★★ | ★★★★ | ★★★★（最新风） |
| 视觉冲击力 | ★★ | ★★★★★ | ★★★★ |
| 信息清晰度 | ★★★★★ | ★★★★ | ★★★ |
| 与现有代码改动量 | **小** | 中 | 中 |
| 实现难度 | 低（纯色+圆角） | 中（环形需 Canvas 画） | 中（需要 blur） |
| 深色模式适配 | 容易（本来就中性） | 容易 | 需重配光斑 |
| 适合谁 | 喜欢"苹果原生"的克制 | 喜欢"每天有成就感" | 喜欢"新、轻、高级" |

### 实现可行性提示（针对本工程）

| 元素 | 可行性 |
|---|---|
| 纯色/圆角/0.5px 分隔线 | ✅ 简单，改 `UiKit` 即可 |
| 4dp 细进度条 | ✅ 简单 |
| 30sp 大标题 | ✅ 简单 |
| **环形进度**（方案 B） | ⚠️ 需用 Canvas 画弧（`drawArc`），约 60 行，可做 |
| **毛玻璃**（方案 C） | ⚠️ Android 端用 `RenderEffect`（API 31+）或半透明+模糊背景图模拟；minSdk 26 需降级方案 | 
| 等宽数字 | ✅ `setFontFeatureSettings("tnum")` 或 monospace |

> **方案 C 的注意点**：真正的 `backdrop-filter` 在 Android 上是 API 31+ 的 `RenderEffect`；
> 你的 minSdk 是 26，所以要么降低要求（半透明色块，不做真模糊），要么按版本降级。
> 方案 A 和 B **全部 API 26 可用**，无兼容风险。

## 五、我的建议

**如果只能选一个：方案 B（深色数据卡）。**

理由：
1. 「今日已赚」是这个 App 的**唯一核心**，深色卡 + 环形进度给它最强的存在感
2. 深浅对比 = 层次感，比方案 A 的"全白"更有记忆点
3. 比方案 C 兼容性更好（无 blur 依赖）
4. 环形进度天然适合"今天赚了多少 / 目标多少"这个语义

**如果想要最"苹果"**：方案 A —— 但要有心理准备，它比较"冷静"，不如现在抢眼。

**如果想试试最新风格**：方案 C —— 但它和"iOS 精致"是两回事，更像"iOS 26 的液态玻璃"，且需要处理 API 降级。

## 六、可以混搭的部分

三套方案不是互斥的，以下元素可以自由组合：

| 元素 | 可独立采用 |
|---|---|
| 30sp 大标题 | ✅ 三套都建议 |
| 圆角从 22 → 14dp | ✅ 三套都建议（这是最见效的一步） |
| 去掉卡片投影 | ✅ A/B 建议 |
| 0.5px 分隔线 | ✅ 三套都建议 |
| 金额字距 -1.2px | ✅ 三套都建议 |
| 4dp 细进度条 | ✅ A/B 建议 |
| 深色主卡 | ⭕ 仅 B |
| 环形进度 | ⭕ 仅 B |
| 毛玻璃 | ⭕ 仅 C |

> 最稳妥的路径：**先用"通用项"改造（改动小、风险低），再决定主卡走哪条路**。
