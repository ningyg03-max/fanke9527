## 一、代码链路核查结论

**逻辑本身是完整的。** 从「触发」到「响/振」的每一环都核对过（源码 + v2.0 交付包 dex 双重确认）：

### 1. 提醒触发链
```
App启动/保存设置/喝水/开机 → WaterReminderScheduler.scheduleNext()
  → AlarmManager（精确闹钟优先；未授权回退非精确，可能延迟）
  → WaterReminderReceiver.onReceive(ACTION_REMIND)
  → isAllowedNow() 判断 → showNotification() → notify(4201)
```

### 2. 通知频道参数（WaterReminderReceiver.createChannel，与原版一致）
| 提醒方式 | 频道 ID | 声音 | 振动 |
|---|---|---|---|
| 仅铃音 (0) | water_reminder_sound | 系统默认通知音 | 关 |
| 仅震动 (1) | water_reminder_vibrate | 无 | 420/220/420ms |
| 铃音和震动 (2, **默认**) | water_reminder_both | 系统默认通知音 | 420/220/420ms |

重要性（importance）= DEFAULT(3)。`setOnlyAlertOnce(false)`，重新提醒会再次发声。

### 3. 权限
- Manifest 有 `VIBRATE` ✓
- 启动时主动申请 `POST_NOTIFICATIONS`（请求码 4300，Android 13+ 必须）✓
- targetSdk = 34（即必须运行时授权通知，不是自动给的）

### 4. 其余核对点
- 通知 ID 4201，与前台服务 4102 不冲突 ✓
- 保存设置 / 喝水 / 稍后提醒 / 开机 后都会重排下一次 ✓
- 提醒仅在 **工作日 + 工作时间内 + 避开午休 + 未达目标** 才弹（否则静默跳过、重排下一次）
- 提醒间隔可选 30/45/60/90/120 分钟（默认 90）；首个提醒 = 上班时间 + 间隔

### 5. 频道是「懒创建」
「喝水提醒」频道只在**第一次提醒实际触发**时才被创建 → **可当诊断依据**（见下）。

## 二、已知结构性风险（继承自原版设计，非本次改动引入）

1. **频道创建后不可变**：Android 8+ 中，频道的 声音/振动/重要性 在创建后由系统与用户接管，App 代码无法再改回来。若频道曾被静音（用户误触或系统行为），升级 App 也不会自动恢复 —— 必须换新频道 ID 重建，或用户在系统设置手动改回。
2. **三个频道同名「喝水提醒」**：系统设置里最多出现 3 条同名条目（如果切换过提醒方式），难以区分。
3. **未设置 bypassDnd**：勿扰模式下必然不响不振（绕过勿扰需用户额外授权）。
4. **重要性默认**：绝大多数情况不弹大横幅（只出现在通知栏/状态栏）；要横幅需提到「高」。
5. 它是**短促通知音 + 短振动**，不是闹钟那种连续铃声。

## 三、分诊表（最可能原因，按此核对）

### 分支 A：提醒时间到了，但通知根本没出现
检查：
1. App 首页喝水卡那行字——显示「下次提醒 HH:MM」还是「⚠️ 通知权限未开启」/「⚠️ 精确闹钟未授权」？
2. 设置 → 通知 → 应用通知 → SalaryJump → 总开关
3. 设置 → 通知 → 高级设置 → **通知历史**（能查到被静音的通知）
4. 设置 → 电池 → 后台使用限制 → 休眠应用/深度休眠应用（在列表里就移除；并将电池设为「不受限制」）
5. 触发条件是否满足：今天是不是工作日（智能模式）、当时是否在工作时段（默认 8:00-17:00）、是否在午休（11:30-12:30）、是否已喝达标

### 分支 B：通知出现了，但无声、无振动
检查：
1. 设置 → 通知 → 应用通知 → SalaryJump → **类别** → 「喝水提醒」→ 声音/振动 开关（注意可能有多条同名）
2. 手机声音模式：**「静音」= 不响也不振**，「振动」= 只振不响
3. 勿扰模式是否开启
4. 设置 → 声音和振动 → 振动强度 → 通知/系统（是否被关到底）
5. 设置 → 声音和振动 → 音量 → **通知音量**（是否为 0）
6. 设置 → 声音和振动 → 通知音（不能是「无」）

### 诊断捷径
打开 设置 → 通知 → 应用通知 → SalaryJump → 类别：
- **连一条「喝水提醒」都没有** → 说明自上次安装以来提醒从未触发过 → 问题在「触发/调度」，不在「声音」
- 有条目 → 至少触发过一次 → 重点查该条目的声音/振动状态

## 四、无需改代码的自测（约 30 分钟内可完成）

1. 首页看喝水卡那行字，拍下「下次提醒」或警告文字
2. 设置 → 提醒间隔临时改 **30 分钟** → 保存（回首页立即显示下次提醒时间）
3. 到点前：手机切「声音」模式、关勿扰、通知音量开一点，等待并观察：
   - 通知弹不弹？有没有声？有没有振？
